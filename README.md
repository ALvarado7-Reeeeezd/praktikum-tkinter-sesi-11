
# Praktikum Tkinter Sesi 11

## Advanced Widgets dan Event Handling

### Deskripsi
Aplikasi Pendaftaran Kegiatan Mahasiswa berbasis desktop menggunakan Python Tkinter.

### Tujuan
Mempelajari penggunaan advanced widgets, event handling, validasi input, menu, dan dialog pada Python Tkinter.

### Fitur
- Form input nama mahasiswa.
- Pemilihan program studi.
- Pemilihan jenis kelamin.
- Pemilihan kegiatan.
- Input alasan mengikuti kegiatan.
- Submit dan Reset.
- Ringkasan pendaftaran.
- Validasi input.
- Messagebox.
- Menu File dan Bantuan.
- Jendela About.

### Cara Menjalankan
1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder project.
3. Jalankan:

   python main.py

### Teknologi
- Python
- Tkinter
- Visual Studio Code
